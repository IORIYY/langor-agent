# LBE-2000 均衡器 通讯中断 排查 SOP

## 故障现象
监控软件无法读取均衡器数据，通讯超时

## 前置条件检查
- 均衡器供电正常
- 通讯线已连接
- 监控软件运行正常

## 排查步骤

### 第1步：确认物理连接
- 检查 RS485 线是否松动
- 检查 A/B 线是否接反
- 检查终端电阻是否接好（120Ω）

### 第2步：检查通讯参数
- 波特率：9600 或 19200
- 数据位：8
- 停止位：1
- 校验：无
- 从站地址是否冲突

### 第3步：检查干扰
- 通讯线是否远离动力线
- 屏蔽层是否单端接地

### 第4步：替换测试
- 换一根通讯线测试
- 换一个通讯口测试

## 常见根因
| 根因 | 占比 | 处理方式 |
|---|---|---|
| 接线松动或接反 | 50% | 重新接线 |
| 参数不匹配 | 30% | 修正参数 |
| 干扰 | 15% | 检查接地 |
| 硬件故障 | 5% | 更换模块 |

## 成本优先级
检查接线 → 修正参数 → 更换通讯线 → 更换模块
