# 工业直流屏 绝缘告警 排查 SOP

## 故障现象
直流屏报绝缘告警，绝缘电阻低于阈值

## 前置条件检查
- 告警是否持续
- 是否刚下雨或环境潮湿

## 排查步骤

### 第1步：确认告警类型
- 正极接地
- 负极接地
- 正负平衡下降

### 第2步：分段排查
- 断开各支路，逐路测量
- 定位到具体支路

### 第3步：现场检查
- 检查该支路电缆绝缘
- 检查接线端子是否受潮
- 检查设备内部是否积尘

### 第4步：处理
- 清理受潮或积尘
- 更换破损电缆
- 恢复后复测

## 常见根因
| 根因 | 占比 | 处理方式 |
|---|---|---|
| 电缆绝缘老化 | 45% | 更换电缆 |
| 受潮 | 30% | 干燥处理 |
| 积尘 | 15% | 清理 |
| 设备内部故障 | 10% | 检修设备 |

## 成本优先级
分段定位 → 清理受潮 → 更换电缆 → 检修设备
