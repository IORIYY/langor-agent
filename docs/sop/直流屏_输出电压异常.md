# 工业直流屏 输出电压异常 排查 SOP

## 故障现象
直流屏输出电压偏离设定值，或波动异常

## 前置条件检查
- 交流输入正常（380V/220V）
- 电池组连接正常
- 负载正常

## 排查步骤

### 第1步：检查交流输入
- 三相电压是否平衡
- 是否有缺相
- 输入电压是否在允许范围

### 第2步：检查整流模块
- 模块工作指示灯状态
- 模块输出电压
- 模块是否均流

### 第3步：检查电池组
- 电池组总电压
- 单体电池电压
- 是否有落后电池

### 第4步：检查负载
- 负载电流是否超限
- 是否有短路

## 常见根因
| 根因 | 占比 | 处理方式 |
|---|---|---|
| 整流模块故障 | 40% | 更换模块 |
| 电池组老化 | 30% | 更换电池 |
| 交流输入异常 | 20% | 检查配电 |
| 负载异常 | 10% | 排查负载 |

## 成本优先级
检查交流输入 → 检查模块 → 检查电池 → 更换硬件
